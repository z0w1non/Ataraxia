# 開発知見記録

この資料は、実装・調査・検証で再利用できる知見を記録する。ユーザーが管理する宣言的要求は `REQUIREMENTS.md`、技術的な仕様は `SPECIFICATION.md` に記載し、ここには知見の根拠、成立条件、実装上の注意を残す。未検証の推測は確定した知見として記録しない。

## 列の定義

| 列 | 用途 |
|---|---|
| ID | 恒久的な参照用識別子。採番後は再利用・変更しない |
| 分類 | GUI、PowerShell、テスト、永続化などの検索分類 |
| 知見・観察 | 再利用する結論を簡潔に記す |
| 適用条件・根拠 | 成立する環境や、確認したコード・実験結果を記す。推測と観察を区別する |
| 設計への反映 | 結論に基づく実装・運用上の扱いを記す |
| 検証方法 | 結論を再確認するテスト、コマンド、観察対象を記す |
| 関連箇所 | 仕様、実装、テストへの相対リンクを記す |

## 識別子の規則

他資料から参照する知見には、項目種別を示す `KNW-NNN` を付ける。`KNW` は Knowledge record を表し、番号は3桁の連番とする。採番済みIDは変更・再利用せず、知見を削除する場合も番号を欠番のまま残す。単なる本文内の手順番号にはこのIDを付けない。

既存の `K-NNN` 参照は同番号の `KNW-NNN` を指す旧別名として予約する。新しい参照には `KNW-NNN` を使い、旧別名を別項目へ再割り当てしない。
